# Fonts

Self-hosted, OFL. Required for the serif headings (no external CDN — site runs offline / file://).

Download Source Serif 4 woff2 from Adobe upstream (OFL):
https://github.com/adobe-fonts/source-serif/releases
or the Google Fonts mirror: https://github.com/google/fonts/tree/main/ofl/sourceserif4

Place these two files here:
- SourceSerif4-SemiBold.woff2   (weight 600)
- SourceSerif4-Bold.woff2       (weight 700)

If absent, headings fall back to Georgia automatically (font-display: swap).
